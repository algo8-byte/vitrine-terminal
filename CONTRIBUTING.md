# Contributing to Vitrine Terminal

Thanks for building on this — that's the whole point of open-sourcing it.

## How to contribute

1. Fork the repo
2. Create a branch: `git checkout -b my-change`
3. Make your change, keep it focused
4. Open a pull request describing what changed and why

## House rules

- **Colour means something.** Teal (`#2DD4BF`) = up/positive only, coral (`#FB7185`) = down/live, amber (`#F5A524`) = attention. Never use them as decoration, and never swap in green/red chart defaults.
- **Numbers in mono.** JetBrains Mono with tabular figures for prices, labels, and data.
- **Quiet by default, loud on event.** Fade layers back rather than deleting them.
- Keep PRs small and single-purpose where you can.

## Bugs & ideas

Open an issue. Screenshots help a lot for UI bugs.
